# Lanzamiento social de Envite Canario

Paquete operativo para abrir Instagram, Facebook y X con una identidad única, propiedad clara y seguridad suficiente desde el primer día.

## Decisión recomendada

- Nombre visible: **Envite Canario**
- Identificador prioritario: **@EnviteCanario**
- Alternativas, por orden: **@JuegaEnvite**, **@EnviteCanarioApp**
- Avatar común: public/images/envite-icon.png
- Imagen de cabecera: public/images/envite-hero.png
- Imagen de producto: public/images/envite-table.png
- Web oficial: URL pública de la versión de prelanzamiento

## Secuencia de apertura

1. Crear un correo propietario del proyecto.
2. Reservar el mismo identificador en Instagram, Facebook y X.
3. Crear Instagram como cuenta profesional de empresa.
4. Crear una Página de Facebook y vincularla con Instagram en un Meta Business Portfolio.
5. Crear la cuenta gratuita de marca en X.
6. Activar autenticación de dos factores mediante una aplicación autenticadora.
7. Guardar los códigos de recuperación fuera del teléfono.
8. Completar nombre, avatar, biografía, categoría y URL de la web.
9. Publicar las tres primeras piezas.
10. Enlazar las cuentas desde la web y entre sí.

## Qué significa “cuenta verificada”

Una cuenta puede ser la presencia oficial de la marca sin insignia azul. La autenticidad inicial se construye con el mismo nombre, el mismo avatar, una URL oficial y enlaces cruzados. Meta Verified y las insignias de X se valoran después de cerrar titularidad, dominio y actividad; no deben retrasar el lanzamiento.

## Puerta de aprobación

Iván debe realizar o confirmar personalmente:

- alta de cuentas,
- aceptación de condiciones,
- datos de identidad y recuperación,
- activación de 2FA,
- cualquier pago,
- solicitud de verificación,
- primera publicación.
